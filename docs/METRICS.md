# 고수템 지표 설계 (시장 검증용)

## 먼저 답해야 할 질문 순서

제품 원칙 1번이 "가방이 콘텐츠, 구매는 따라온다"예요. 그래서 검증 순서도 같아요.

| 순서 | 질문 | 왜 먼저인가 |
|---|---|---|
| 1 | **입문자가 고수 가방을 끝까지 보고, 물건별로 "살지/말지"를 고르는가** | 이게 안 되면 구매도 고수 등록도 의미 없음. 핵심 가치 검증 |
| 2 | **고른 다음 판매처로 실제로 나가는가** (새상품·중고·나눔 중 어디로) | 수익 모델(제휴·중고 연결) 가능성. 1차는 결제가 없으니 "외부 클릭"이 구매 대리 지표 |
| 3 | **다시 올 의사를 남기는가** (스크랩·팔로우·사전신청) | 리텐션 대리 지표. 심사에서 묻는 "사전신청 수"가 여기 |
| 4 | **고수가 자기 가방을 열려고 하는가** | 공급 측. 1차는 컨시어지(창업자가 대신 만듦)라 "데뷔 흐름 시작·완주율"만 봐도 됨 |

"구매가 먼저냐, 가방 등록이 먼저냐"의 답: **구매 의도(2번)가 먼저**예요. 공급은 1차 라운드에서 창업자가 직접 채우기로 했고, 수요가 증명돼야 고수를 설득할 재료가 생겨요.

## 북극성 지표 1개

**가방 1개를 본 사람 중, 물건 1개 이상 "어디서 살지"까지 고른 비율** (`channel_pick` 세션 ÷ `bag_view` 세션)

## 퍼널과 기록되는 이벤트

### 수요 퍼널
| 단계 | 이벤트 | 담는 값 |
|---|---|---|
| 방문 | `visit` | sid, 화면 너비, referrer, utm_source/medium/campaign |
| 화면 이동 | `screen` | route(home / 가방 id / preorder / intern…) |
| 검색 | `search` | 검색어 |
| 물건별 경로 확정 | `channel_pick` | bag, item, ch(new/used/share…), k(몇 번째 판매처) |
| 판매처로 나감 | `outbound` | host(쿠팡·당근·네이버…), 링크 글자 |
| 팝업 열기 | `modal` | type(checkout 일괄구매 / listing 매물 / recommend / supply…) |
| 저장 의사 | `scrap`, `follow` | bag, on(1/0) |
| 사전신청 | `preorder_done` | 관심 상황, 가방 열 의향 (이메일은 Netlify Forms 에만 저장, 지표 저장소엔 없음) |

### 공급 퍼널
| 단계 | 이벤트 |
|---|---|
| 고수 데뷔 팝업 열기 | `modal` type=supply |
| 단계 진행 | `supply_step` step 1(사진)·2(입력)·3(초안)·4(공개) |

## 2주 안에 뽑을 지표 10개

1. 유입 채널별 세션 수 (utm_source: insta / everytime / friend)
2. 홈 → 가방 상세 진입률
3. 가방 상세 체류 중 `channel_pick` 1회 이상 세션 비율 ← **북극성**
4. 물건당 평균 `channel_pick` 수, 가방당 다 고른(일괄구매 팝업 연) 비율
5. 경로 비중: new / used / share (중고·나눔 선택 비율이 높을수록 "쇼핑몰과 다름" 근거)
6. `outbound` 클릭률과 host 분포 (제휴 수익 가능성)
7. 스크랩·팔로우 전환율
8. 랜딩 → 사전신청 전환율, 사전신청자의 "가방 열 의향" 비율
9. 고수 데뷔 팝업 연 비율과 4단계 완주율
10. 재방문율 (같은 sid 가 2일 이상 `visit`)

## 데이터 보는 법

- 요약: `GET /api/track?days=7&token=…` → 일별 세션 수·이벤트 수 JSON
- 원본: `GET /api/track?day=2026-10-27&token=…` → NDJSON (스프레드시트로 열어 퍼널 계산)
- 토큰은 Netlify 환경변수 `TRACK_TOKEN` 에 넣어요. 없으면 읽기 전부 403.
- 세션 녹화·히트맵이 필요하면 Microsoft Clarity(무료)를 `index.html` 에 추가. 이 저장소 지표와 역할이 달라요: Clarity = 화면 어디서 막히는지 "보기", 여기 = 퍼널 "세기".

## 개인정보

익명 세션 번호·화면 너비·referrer·UTM·이벤트만 저장. 이메일·이름·IP 는 저장하지 않아요. 사전신청 이메일은 Netlify Forms 에만 있어요.
