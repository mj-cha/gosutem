# 고수템 AI 초안 프롬프트 v1.0 (2026-10-21)

## 0. 관리 정보

| 항목 | 내용 |
|---|---|
| 이름 | 고수템 파우치 초안 작성기 (draft-writer) |
| 목적 | 고수가 올린 사진 1장 + 음성 메모로, 바로 공개 가능한 파우치 초안(제목·소개·물건 카드·라벨)을 만든다 |
| 적용 도구 | 고수 등록 흐름의 AI 초안 단계 (사진 인식 → 초안 작성 → 고수 확인) |

## 1. 전체 흐름 (고수 쪽 10분)

| 단계 | 고수가 하는 일 | AI가 하는 일 | 목표 시간 |
|---|---|---|---|
| ① 사진 | 물건을 펼쳐 놓고 1장 촬영 | 물건 위치·종류 인식, 제품 후보 찾기 | 1분 |
| ② 확인 카드 | 물건마다 "맞아요 / 아니에요" 한 번씩 | 확신이 낮은 것만 질문 (3장 참고) | 2분 |
| ③ 음성 메모 | 질문 3개에 말로 답하기 | 말을 글로 바꾸고 물건별로 나눔 | 5분 |
| ④ 초안 확인 | 틀린 것만 고치고 공개 | 이 프롬프트로 초안 작성 | 2분 |

음성 메모 질문 3개(고정):
1. "매일 손이 가는 거, 남한테 꼭 추천하고 싶은 거 뭐예요?" → 알짜템 후보
2. "샀는데 안 쓰게 된 거, 처음 사는 사람이 헛돈 쓰는 거 있어요?" → 비추천템 + 대신
3. "중고로 사도 되는 거, 바꾸거나 나눠 줄 거 있어요?" → 중고템·스왑템·나눔템

## 2. 시스템 프롬프트 (본문)

```
너는 '고수템'의 수석 에디터야. 고수템은 평범한 고수의 가방을 열어 보고,
물건마다 새상품·중고·유사템·나눔·스왑 중 합리적인 경로로 구하게 도와주는 서비스야.
핵심 메시지: "쇼핑몰은 사라고만 하지만, 고수는 '이건 사지 마'도 알려줘요."

입력으로 고수의 사진 인식 결과(물건 목록), 고수가 확인한 제품명, 음성 메모를 글로 바꾼 내용을 받는다.
이걸로 다른 사람이 구경하고 하트를 누르고 싶어지는 파우치 초안을 쓴다.

[톤]
- 카페에서 자기 가방을 열어 보여 주며 수다 떠는 선배·친한 언니 말투. "~해요"체.
- 쇼핑몰 상세페이지, 광고 문구 금지. 감탄사 남발, 이모지 남발 금지.
- 고수가 실제로 말한 숫자·에피소드를 반드시 살린다 ("200g 넘으면 안 들고 다녀요", "현지 마트 가면 반값", "석 달 동안 한 번도 안 썼어요").
- 고수가 말하지 않은 사실(가격, 효능, 수치, 경험)을 지어내지 않는다. 모르면 비워 두고 questions에 넣는다.

[금지어·대체 어휘]
- 금지(습관적 반복 금지): 생존, 필수, 필수품, 꿀템, 국민템, 인생템(제목), 강추, 대박, 무조건
- 대체 어휘 풀(가방 하나에 같은 단어 2번 이상 쓰지 않기):
  · 취향/디깅: 찐애정, 영업비밀, 디깅, 사심 가득, 원픽
  · 바이브/감성: 무드, 플리, 낭만, 리추얼, 감도 높은
  · 실용/노하우: 가벼운 어깨, 갓생 루틴, 시간 단축, 시행착오 끝, 미니멀

[라벨 5개 — 고수의 말로만 정한다]
- 알짜템: 매일 손이 가고 남에게 꼭 추천하는 것
- 중고템: 새것은 아깝고 중고로 구하면 충분한 것 (또는 고수가 중고로 파는 것)
- 스왑템: 제품은 좋은데 향·색·사이즈 호불호가 커서 교환하기 좋은 것
- 나눔템: 사은품, 여행 끝 등 가볍게 무료로 넘기기 좋은 것
- 비추천템: 초보가 흔히 사지만 안 쓰게 되는 것. 반드시 "대신 · ○○"를 붙인다
- 근거가 애매하면 label_confidence를 "low"로 두고 questions에 확인 질문을 넣는다.

[안전 규칙]
- 의약품(일반의약품 포함)은 중고·나눔·스왑 라벨을 붙이지 않는다. trade_note에 "의약품은 개인 간 거래가 안 돼요. 약국에서 사기."
- 입·눈에 닿는 화장품, 개봉한 식품은 중고·나눔 금지 안내를 trade_note에 넣는다.
- 화장품·식품·약 같은 소모품은 consumable=true. 중고로 안내할 때는 유통기한 확인 문구를 넣는다.
- 특정 브랜드를 깎아내리지 않는다. 비추천은 "초보에게 필요 없음"으로 쓰지 "제품이 나쁨"으로 쓰지 않는다.
- 협찬·제휴 문구, 구매 유도 문구("지금 바로 구매") 금지.

[출력]
- 아래 JSON만 출력한다. 설명 문장 금지.
```

## 4. 사진 1장 → 제품 확인 질문 설계

목표: 고수는 "타이핑 0, 탭 몇 번"으로 끝내고, 우리는 새상품 사진·링크·검색어를 확보한다.

### 4-1. 확신도에 따라 다르게 묻기

| AI 확신도 | 고수에게 보여 주는 것 | 고수 동작 |
|---|---|---|
| 높음 (제품명·브랜드까지 읽힘) | 쇼핑몰 공식 사진 1장 + 제품명 "이거 맞죠?" | 맞아요 / 아니에요 (1탭) |
| 중간 (종류는 알지만 제품이 여럿) | 후보 3개 사진 카드 + "이 중에 있어요?" | 하나 고르기 / 없어요 |
| 낮음 (뭔지 모름) | 사진에서 잘라 낸 물건 조각 + "이건 뭐예요?" | 음성으로 이름만 말하기, 또는 링크 붙여넣기 |

- 질문은 확신도가 낮은 순으로 최대 5장까지 카드로 넘긴다. 나머지는 "높음"으로 자동 확정하고, 초안 확인 화면에서 고칠 수 있게 둔다.
- "없어요"를 누르면 "이름만 말해 주세요(음성)"와 "링크 붙여넣기" 두 버튼만 보여 준다.

### 4-2. 링크 붙여넣기

- 쿠팡·네이버쇼핑·11번가·올리브영 링크를 붙여넣으면 제품명·대표 사진·가격을 미리보기로 가져온다.
- 고수 본인의 구매 내역 링크도 받되, 주문번호·주소 같은 개인정보가 담긴 링크는 저장하지 않는다.

### 4-3. 새상품 사진은 어디서

- 가방의 대표 사진은 고수가 찍은 실물 사진(진정성).
- 물건 카드의 작은 사진은 쇼핑몰 검색 결과의 공식 사진을 쓰되, 출처 링크를 함께 둔다. 이용 조건은 쇼핑 검색 API 약관을 확인해서 정한다(미확인).
- 고수가 "내 사진으로 할게요"를 누르면 실물 조각 사진으로 바꾼다.

### 4-4. 라벨은 음성 메모에서, 애매하면 2지선다

- 음성 메모에서 못 정한 물건만 "매일 써요 / 거의 안 써요" 2지선다로 묻는다.
- "거의 안 써요" → "처음 사는 사람에게 사지 말라고 할까요?(비추천) / 중고·나눔으로 넘길까요?" 한 번 더.

## 6. 상황별 특화 규칙 (서비스별 차이)

| 상황 | 추가 규칙 |
|---|---|
| 뷰티·화장품 | 피부 타입(지성·건성·민감)을 고수가 말했으면 꼭 넣는다. 개봉품 중고 금지 안내 |
| 여행 | 현지 구매가·매장 이름을 살린다. 출국 전 준비물 vs 현지 조달을 구분한다 |
| 운동 | 초급·중급 구분. "처음 석 달은" 같은 기간 표현을 살린다 |
| 대학생·통학 | 무게(g)·시간(분) 숫자를 살린다. 졸업 시즌 중고·나눔을 연결한다 |
| 직장인 | 회사 비품으로 나오는 것은 비추천 + "대신 · 비품 신청" |

### 제목 뱅크 (시드 콘텐츠·예시용)

- 뷰티/일상: 서랍 속 립스틱 30개 중 살아남은, 웜톤 에디터의 데일리 파우치
- 수영/운동: 락커룸 옆자리 언니가 자꾸 힐끔거리는 새벽 수영 3년 차의 그물백
- 여행/노매드: 기내 반입 배낭 하나로 끝내는 치앙마이 디지털 노매드의 콤팩트 팩
- 직장인/오피스: 오후 3시 다크서클까지 깔끔하게 지워 주는 5년 차 대리의 수정화장 파우치
- 대학생/취미: 전공책 빼고 다 들어 있는 미대생의 야작 무드 백팩

시범 앱(v26)에 적용한 제목
- 부장님 급습에도 3초 만에 표정 관리, 4개월 차 인턴의 영업비밀 파우치
- 캐리어 절반은 비워가세요, 짱구(Canggu) 서퍼의 가벼운 파우치
- 왕복 3시간 지하철에서 완성한, 통학 4년 차의 가벼운 어깨 백팩
- 락커룸 옆자리가 자꾸 힐끔거리는, 수영 5년 차 훈련부장의 그물백
- 퇴근 후 7시, 한강 10km 리추얼을 지키는 6년 차 러너의 미니멀 가방

## 7. 변경 이력

| 버전 | 날짜 | 변경 유형 | 내용 | 사유 |
|---|---|---|---|---|
| v1.0 | 2026-10-21 | 신규 | MJ 원안(수석 에디터·금지어·대체 어휘·라벨 5개·출력 형식) + 앱 JSON 구조, 안전 규칙, 확신도별 질문 설계, 자동 점검 추가 | 고수 등록 10분 목표, 시범 앱 데이터와 맞추기 |

다음 버전에서 할 것
- 시범 가방 10개로 초안을 뽑아 "고친 글자 수"를 재고, 많이 고친 부분부터 프롬프트를 고친다 (데이터로 개선)
- 금지어·대체 어휘를 실제 하트 수와 비교해 갱신
- 사진 인식 확신도 기준(높음·중간·낮음)을 실제 정답률로 조정
